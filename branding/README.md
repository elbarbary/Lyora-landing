# Lyora — The Fold

Approved concept 10: folded lowercase y in plum and rose, with the custom lowercase wordmark.
These PNG masters are shared by the app and landing repositories. Keep the four masters identical across both repositories.

Run `python3 -m pip install Pillow` and `python3 scripts/generate_brand_assets.py` from the repository root after changing a master. The script exports the sizes required by this repository without stretching the artwork. The landing site uses versioned URLs to refresh cached branding.

Use the horizontal logo for navigation and app headers, the stacked logo for launch screens, and the symbol for favicons. White treatments use the same image alpha, never a separately drawn approximation. Never mirror the logo in Arabic layouts.

Target palette: plum #4C1535, rose #C8336B, ivory #FCF8F5. The masters are raster artwork; do not substitute a font for the approved wordmark.
